ALG = Arch Linux GUI 提供了图形化安装程序，是继 archinstall 后更便于安装的 Arch Linux 版本（不算新的发行版，只是定制化版 Arch）

§ 下载

前往北外源，选择 77223 (plasma, 2022.05)（当然可以选自己喜欢的桌面环境或者窗口管理器）。

§ 安装

使用 Rufus 或 Etcher 制作启动 U 盘，或者直接使用 Ventoy（推荐）制作多系统启动盘。（刷新过程略）

进入 KDE Plasma 桌面

在左下角开始菜单里，点击 Applications > System > Install Arch Linux（在窗口管理器版本需使用快捷键 Win + D 打开 Rofi，搜索 Install Arch Linux），

为什么是英文界面，因为这系统使用的 Noto 字体，而维护者认为 Noto-CJK 字体太大了，徒增镜像大小，那为啥窗口管理器版本有中文就不知道了。

等加载完后，出现选择语言，这里先选英文（因为没带 CJK 字体）

点击 Next，时区选 Asia/Shanghai

点击 Next，键盘布局这里根据实际选择，比如我是戴尔，一般选默认不会出错

点击下一步(Next)，分区方式选手(Manual)动分区(partitioning)

点击下一步，选中最下面分到的 Free Space（这里制作双系统，只给了 50GiB 空间），然后点击右下角 Create

设置以下值

空间大小文件系统挂载点标志
300 MiBfat32/boot/efiboot

选中 Free Space，点击右下角 Create

设置以下值

空间大小文件系统挂载点标志
1000 MiBlinuxswapswap

选中 Free Space，点击右下角 Create

设置以下值

空间大小文件系统挂载点标志
3000 MiBext4/root

选中 Free Space，点击右下角 Create

设置以下值

空间大小文件系统挂载点标志
19899 MiBext4/home

这里我们共创建了四个分区

点击下一步，设置用户名、系统名和密码，设置管理员密码与登录用户相同

点击下一步，可以看到当前自定义安装信息，点击 Install

然后就是喝茶时间，整个过程不到 10 分钟（我用了 8 分钟）

安装完成，选中 Restart Now，然后 Done

重启后拔出 U 盘

打开 Terminal，输入

回车后输入密码

直接回车

再次回车

这就基本完成了。
