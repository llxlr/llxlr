§ 在子模块中工作

比如从本地子模块检出一个分支stable：

尝试用--merge选项来更新子模块。这时将会看到服务器上的这个子模块有一个改动并且它被合并了进来。

当我们对子模块做一些本地的改动而同时其他人推送另外一个修改到上游时，在此时更新子模块，就会看到我们在本地做了更改时上游也有一个改动，需要将它并入本地。

若忘记--rebase或--merge，Git会将子模块更新为服务器上的状态，并且会将项目重置为一个游离的HEAD状态。

§ 别名

为命令设置别名，因为它们非常长而又不能设置选项作为它们的默认选项。

若计划大量使用子模块，这样当你想要更新子模块时可以简单地运行git supdate，或git spush检查子模块依赖后推送。
